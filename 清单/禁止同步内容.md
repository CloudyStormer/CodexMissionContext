# 禁止同步内容

以下内容不得进入本仓库：

- `~/.codex/auth.json`
- `~/.codex/sessions/`
- `~/.codex/archived_sessions/`
- `~/.codex/history.jsonl`
- Codex、浏览器或操作系统的数据库和缓存
- `.env`、API Key、OAuth Token、Cookie、密码
- SSH、TLS 或其他私钥
- 项目中已经由独立 Git 仓库管理的完整代码副本
- 未经压缩、包含大量隐私或重复内容的原始聊天全文

任务记录允许保存完成工作所必需的路径、命令、错误信息和公开链接，但不得包含凭证值。
