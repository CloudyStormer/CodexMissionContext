# 项目：CodexMissionContext

最近更新：2026-07-28

## 一句话说明

为 A、B 两台设备提供统一的项目、任务、对话语义和个人 Skill 持久化同步。

## 项目目标

- 每项 Codex 任务开始前拉取最新上下文。
- 共同长期任务结束后形成可续接记录并推送 Git；临时对话不自动保存。
- A、B 两台设备平等交替使用，任一设备都能从最新记录继续并及时写回，不设主设备或备用设备。
- 项目代码继续使用各自仓库，本仓库只保存上下文和同步规则。
- 个人 Skill 以本仓库为唯一事实来源。
