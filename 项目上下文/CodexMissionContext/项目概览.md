## 已确认决定

- A、B 没有主次关系；哪台设备被使用，哪台就先拉取、继续并及时推送。
- Windows 共同项目只放在 `D:\.aaProject-Bruce\`，不在 C 盘创建共同项目或 worktree。
- 项目代码由各自 Git 仓库管理；本仓库只保存精准压缩上下文、清单、映射和 Skill。
- 日常同步不逐文件研究业务差异，也不提交原任务尚未确认的改动。
- 每次同步与提交统一由当前同步任务直接操作各仓库，不再把 Git 动作分派到独立项目任务并逐项要求用户确认；不可避免的权限阻塞只合并报告一次。
- “开始同步”要求尽可能完整拉取，但不能突破真实权限、凭证、冲突和离线边界；不可达部分必须登记并重试。
- “开始同步”不授权 stash、暂存、提交或推送脏业务仓库；只对干净且可 fast-forward 的工作树拉取。
- 共享布局只保存逻辑 ID 和版本，通过正式 API 或用户可见界面稳定合并；不复制或写入 Codex 原始状态、数据库或 session。
- `AI学习` 永久排除，除非用户以后明确改变范围。
