# 项目：FIFA VAR 数字扫描前端

最近更新：2026-08-07

## 一句话说明

面向 FIFA 赛事球员数字扫描，管理多角度照片、3D 模型及相关平台能力的 React 前端。

## 项目目标

- 接收影棚内多相机为每位球员拍摄的多角度照片，并将照片提交云端处理。
- 管理球员的 3D 模型、中央仓库和检测平台能力。

## 技术结构

- 技术栈：React 19、React Scripts 5、Axios、Zustand、Ant Design / MUI、Three.js。
- 前端入口：以 `package.json` 中 `start` / `build` 脚本为准。
- 外部依赖：影棚局域网主机、云端对象存储/业务 API、后续 AI 建模链路。
