## 三、本周已形成的硬成果

### 1. FIFA 图片上传方案

- 完成现状代码审阅：当前高清照片未可靠落盘，任务生命周期仍受浏览器标签页影响。
- 形成业务化传输链路：`影棚主机 → 笔记本后台搬运程序 → 笔记本硬盘 → 云端`。
- 明确本地可靠与云端完成必须分开管理；浏览器关闭、断网或重启后任务应能恢复。
- 完成容量基线：每名球员约 180 MB；300 人约 54 GB/天，500 人约 90 GB/天。
- 交付 21 页 Word 技术架构文档，包含 4 张图、18 个表格；本周未修改业务代码。

### 2. 联想元宇宙项目审查

- 审查约 6,631 个跟踪文件、约 15 GiB 跟踪内容，其中资源约 14 GiB。
- 识别约 1.48 GiB 重复 Blob，以及大量复制式实现和疑似孤儿候选。
- P0：前端凭证暴露、未清洗 HTML 注入。
- P1：事件、定时器、WebGL、视频资源释放缺陷；请求状态错误；缺少真实测试和 CI 门禁。
- 治理原则：先处理安全，再补烟测和质量门禁，最后治理资产与架构；不能凭文件名或静态零引用直接删除。

## 四、下周 To-do List

### P0：公司工作优先闭环

- [ ] **球员资源一致性核对**
  - 明确两个待比较的数据源、环境和快照时间。
  - 以球员唯一 ID 对比数量、关键字段、照片/模型资源、版本及可用校验值。
  - 输出“完全一致 / 缺失 / 多余 / 字段冲突 / 文件损坏或不可访问”的差异表。
  - 验收：不存在未解释差异；每个差异都有原因、责任人和处理状态。

- [ ] **元宇宙平台可用性验证**
  - 确认正式与测试访问域名、目标网络和账号权限。
  - 检查 DNS、HTTPS、登录、首页、用户指定关键业务页面、核心 API、实时连接和 3D 资源加载。
  - 记录测试时间、环境、结果、截图/日志和问题复现步骤。
  - 验收：形成一份可用性清单，明确“可用、部分可用或不可用”，不能只说“页面能打开”。

- [ ] **AI 工作流黄金样本闭环**
  - 优先选择 AI English Learning，暂停继续横向铺更多样本。
  - 完成代码审查、缺陷处理、QA、本地后端、集成验证、部署预检、最终验收和复盘。
  - 验收：产生完整、可追溯、可恢复的一次端到端运行记录。

### P1：方案转入可执行阶段

- [ ] **评审 FIFA 图片上传架构**
  - 确认“影棚可拆”标准：一份加密本地副本是否足够，还是必须本地双副本或云端完成。
  - 确认照片保留期限、每日人数、最大断网天数和目标设备磁盘配置。
  - 验收：业务与技术结论有明确记录，可据此拆任务。

- [ ] **定义 FIFA 上传 POC**
  - 单名球员 36 张、约 180 MB 照片可完整落盘并校验。
  - 浏览器关闭、服务重启和断网恢复后任务不丢失。
  - 本地可靠状态与云端完成状态分离，单图失败可重试和对账。
  - 验收：POC 范围、接口、测试用例、成功指标和负责人齐全；评审前不直接开发生产版本。

- [ ] **确定元宇宙首批优化范围**
  - 首批只处理凭证轮换协作、HTML 安全和确定性资源生命周期问题。
  - 同时建立关键 URL 烟测、资源 404、secret scan 和最小 CI 门禁。
  - 验收：获得明确修改授权；每项修复都有验证，不夹带全量重构和批量资源删除。

- [ ] **建立 AI Workflow Scale 基线**
  - 为 `state / approval / artifact / event` 建立强 Schema 和 CI 校验。
  - 从真实记录自动生成 Control Center 数据和项目复盘，不再依赖演示数据。
  - 统一统计：阶段周期、实际工时、审批等待、一次通过率、返工次数、P0/P1 缺陷、自动检查覆盖率、恢复成功率、Token/费用和产物可追溯率。
  - 扩规模门槛：连续 3 次运行达到 100% 产物可追溯、100% 可复现构建、至少 90% 门禁自动校验、恢复演练通过且无遗漏的 P0/P1 后，再提高并发项目数。

### P2：能力建设与技术探索

- [ ] **数字人骨骼绑定与动作驱动调研/POC**
  - 明确 3D 模型格式、骨骼规范、坐标/比例、目标运行环境和动作数据授权。
  - 选一个代表性数字人完成绑定、蒙皮、动作重定向和目标环境播放。
  - 验收：至少验证 3—5 个代表动作，无明显穿模、关节翻转或网格塌陷；形成可行性结论和批量化风险清单。

- [ ] **AI 开发四周学习路线**
  - 第 1 周：大模型/API/上下文与提示词基础。
  - 第 2 周：工具调用、Agent 和结构化输出。
  - 第 3 周：RAG、数据处理、评测和防幻觉。
  - 第 4 周：前后端集成、部署、监控、成本与安全。
  - 验收：每周完成一个可运行小作品、一份复盘和一组可复用模板，而不是只看资料。
