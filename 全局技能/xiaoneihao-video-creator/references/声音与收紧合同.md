# 声音与收紧合同

## 默认声音登记

用户没有另行确认时，小耗儿使用：

- 内部声音配置编号 `voice_profile_code`：`VO-XH-01`
- 普通话青年男声，中低音，近讲干声
- 略疲惫但清醒，冷静、利落，不油腻、不播音腔
- 正常语速约每秒 5.0—5.6 个汉字
- 情绪只改变力度和停顿，不改变基础音色、音高、共振峰、年龄感、性别感或口音

首次批量生成前，先用 6—10 秒完整句制作无 BGM、无混响、无环境声的干声参考，并登记提供方、模型版本、平台实际 `provider_voice_id` 或参考音频项目路径与 SHA-256、seed 和复现参数。`VO-XH-01` 只是内部配置编号，不是平台 Voice ID。若视频工具不能引用同一声音资产，使用同一已验收 TTS / 配音源生成干声后再同步混入；若无法复用同一声音源，停止批量生成。不得声称仅凭提示词已经实现绝对声纹一致。

## 对白片：直接有声模式必须原样包含

只有视频工具能绑定已经验收的同一 `provider_voice_id` / `reference_audio` 时才使用本模式。

```text
【有声输出硬要求】本片段必须生成并保留可听见的同步中文人声，成片必须有声音。禁止静音，禁止只有口型、只有字幕、只有环境声或把对白省略。

【全片固定音色】当前说话角色：小耗儿；内部声音配置编号 voice_profile_code：VO-XH-01；平台实际 provider_voice_id / reference_audio：必须填入已验收登记值，禁止留空，禁止把 VO-XH-01 冒充平台 Voice ID。全片始终使用同一位普通话青年男声：中低音、近讲干声、略疲惫但清醒、冷静利落；语速约每秒5.0—5.6个汉字。跨所有 clip 固定同一实际声音资产、音高、共振峰、年龄感、性别感、口音、话筒距离和录音质感。情绪只改变力度与停顿，不得改变基础音色。若平台支持参考音频、Voice ID、seed或模型版本，必须复用同一组设置。

【对白执行】只允许当前角色开口，其他人物全程闭嘴。只说下方指定对白一次，必须逐字一致；不复述、不改写、不添加语气词、不抢词、不叠声、不由错误角色开口。0.00—0.20秒闭嘴准备；按本镜头时码开始和结束；最后至少保留0.25秒闭嘴定格。

【声音禁止项】禁止音色漂移、共振峰漂移、突然变调、忽快忽慢、机械电音、双重人声、回声、混响、爆麦、吞字、口吃、错误重音、方言、英语口音、背景对白、自动配乐和自动音效。
```

配角说话时只替换“当前说话角色”、内部 `voice_profile_code`、已经验收的实际 `provider_voice_id` / `reference_audio` 和该角色唯一声音描述，其他句式不得换同义词。一个角色一旦登记，后续全部片段逐字复用。

## 无对白片段必须原样包含

```text
【有声输出硬要求】本片段必须生成并保留可听见、连续、自然的环境底噪，生成源片和交付视频都必须有非空音轨。禁止静音，禁止空音轨，禁止用对白、配乐或自动一次性音效代替环境底噪。

【无对白执行】当前说话角色：无；voice_profile_code：不调用；provider_voice_id / reference_audio：不调用。所有画面人物全程闭嘴，禁止说话、哼声、叹气、笑声、口型、画外音、设备中的可辨识人声和背景可辨识人声。

【环境原声】只生成与场景匹配的极轻、连续底噪，从头到尾可听但不抢画面；一次性脚步、撞击、水滴、餐具、设备提示音和人群反应全部后期添加。
```

## 视频工具不能绑定声音资产时

只在工具确实不能引用同一 `provider_voice_id` / `reference_audio` 时使用外部固定配音模式。它与上面的直接有声模式二选一，禁止把两套声音块同时复制进同一提示词：

1. 先用同一个已验收 TTS / 配音声音生成本片全部干声，固定提供方、模型、实际 Voice ID、参考音频、seed、语速和录音参数。
2. 视频源片仍须带连续、可听的极轻环境底噪，禁止静音；按已经锁定的干声时码只生成对应自然口型，不让视频模型另造随机人声。
3. 将同一干声无损同步混入源片，导出新的有声中间片；中间片才进入剪辑。最终片必须有清晰中文人声和非空音轨。
4. 对白、开闭口时码、角色嘴部状态和全部动作收紧约束与直接有声模式相同。无法稳定对齐口型或无法复用同一配音资产时停止该批次。

外部固定配音模式用下面的完整声音块替换直接有声模式的“有声输出硬要求”和“全片固定音色”块：

```text
【有声输出硬要求｜外部固定配音模式】生成源片和有声中间片都必须有非空音轨，禁止静音。视频工具不得生成随机对白人声；源片必须输出连续可听的极轻环境底噪。随后必须把下方已经验收的同一干声同步混入，形成含清晰中文口播的有声中间片，才能进入剪辑。

【全片固定音色】当前说话角色：[角色名]；内部声音配置编号 voice_profile_code：[内部编号]；平台实际 provider_voice_id / reference_audio：[必须填入已验收登记值]。禁止留空，禁止把内部编号冒充平台 Voice ID。全部干声固定同一提供方、模型版本、实际声音资产、seed、音高、共振峰、年龄感、性别感、口音、话筒距离和录音质感。

【对白与口型执行】干声只说指定对白一次，逐字一致；不复述、不改写、不添加语气词。源片嘴型只按该干声的精确起止时码运动，其他人物全程闭嘴；最后至少保留0.25秒闭嘴定格。混入后再次检查逐字对白、口型同步和非空音轨。
```

## 每条视频提示词的动作块

```text
【动作收紧】固定机位。本片段只发生一个主要动作，动作幅度小而清楚；说话期间身体位置、角色结构、服装、道具和背景不变。其他人物静止、闭嘴、不抢戏。结尾动作完全停止并留出剪辑点。

【画面禁止项】禁止多人同时开口，禁止复杂走位、绕行、追逐、身体接触、突然转身、边走边拿道具、肢体增生、嘴型错位、牙齿或舌头、角色变形、人物增减、道具复制或消失、背景路人运动、镜头漂移、自动推拉、焦点呼吸、曝光闪烁、画风跳变、自动字幕、数字、Logo和水印。
```

## 单片段完整结构

每条按以下顺序写，不能引用“同上”：

1. 时长、画幅，以及一张代表性关键帧；大状态变化片段才使用首尾两张状态帧
2. 永久角色与场景连续性
3. 有声输出硬要求
4. 对白片写实际声音资产与固定音色；无对白片写不调用人声和连续环境底噪
5. 对白片写精确对白与声音时码；无对白片写全员闭嘴时段
6. 一个主要动作和镜头设置
7. 环境底噪要求
8. 声音与画面禁止项

## 多片段声音验收

1. 先验收小耗儿第一条声音样片，再生成后续片段。
2. 检查每个生成源片和最终导出文件都确实有音轨，且不是空音轨。
3. 顺序试听相邻片段，检查音高、口音、语速、共振峰和录音距离是否跳变。
4. 任何一个 clip 声线漂移，只重生成该 clip；不得通过变调把不同人物硬修成同一人。
5. 最终混音对白建议约 `-16 LUFS`，峰值不高于 `-1 dBTP`；统一 BGM 在对白下压约 6—9 dB。
