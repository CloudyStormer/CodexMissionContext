# 多视图与逐帧身份锁

## 参考层级

1. `assets/brand/resistor-mascot-identity-master-original.jpg` 是唯一最高身份源，决定正面比例、五官、轮廓、色彩与核心结构。
2. `assets/brand/resistor-mascot-multiview-v1/` 只解决正、背、左、右、左 3/4、右 3/4 的空间结构，不能覆盖或“优化”原版。
3. 单集关键帧只负责动作、服装、道具和场景连续性，不能升级为新母版。
4. 发生冲突时依次服从：永久原版母版 > 对应角度参考 > 已验收上一状态帧 > 风格与场景效果。

## 圆度硬门槛

- 永久母版主体是横向饱满的近圆机体，不是纵向拉长的鸡蛋；圆度只测机体黑色外轮廓，不含头顶黄蓝标志、手脚。
- 正面、背面和左右 3/4 的机体宽度不得低于高度的 95%；纯侧面允许极轻透视压窄，但宽度不得低于高度的 92%。
- 先验收外轮廓，再验收五官和纹路。特征相似但轮廓高瘦、上窄下尖或鸡蛋化，仍判为身份失败并重生成。

## 验收

1. 图片：对照永久正面母版与对应角度参考，检查轮廓、五官、腰带高度、锯齿纹、电路纹、头顶标志、嘴和四肢。
2. 视频：至少抽查第 0 帧、25%、50%、75% 和最后一帧；有条件时逐帧检查。
3. 任一抽查帧出现结构漂移、纹路重排、增生、消失、换脸或物种化，整段判失败并重生成。
4. 不通过裁切坏帧、遮挡、加字幕或声称“只闪了一下”放行身份错误。
