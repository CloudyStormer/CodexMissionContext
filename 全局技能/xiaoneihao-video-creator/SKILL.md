# 小耗儿短视频创作

把用户原始创意转为可生成、可配音、可剪辑、可续接的单集素材。保留原稿作为来源，另建版本化生产稿，不暗中覆盖已确认版本。

## 开工

1. 按当前仓库规则同步上下文并检查 Git 工作树；保留用户已有修改。
2. 读取项目入口、账号定位、视频流程、剧集索引、当前或上一集 README，以及品牌角色锁定文件。
3. 使用 `aidrama` 组织剧情、分镜、连续性与交付；生成图片时使用 `imagegen`。
4. 没有指定集数时使用索引中的下一个编号；与旧集高度重复时保留为新版本或续集，并在 README 说明关系。

## 锁定创作输入

把用户明确提供的画幅、时长、风格、角色、台词、字幕、音乐和音效视为最高优先级。只在缺失时采用项目默认值，并把默认值写入工作假设。

固定主角必须使用仓库永久母版 `assets/brand/resistor-mascot-identity-master-original.jpg`。它是最高身份源；`assets/brand/resistor-mascot-multiview-v1/` 是从原版派生的机位参考，不能反过来覆盖原版。只允许改变动作、服装、道具、场景、光线、材质和有限表情；不得改变横向饱满的单一近圆身体、永久母版圆度与宽高比、五官、头顶黄蓝标志、浅灰电阻区域、锯齿纹、蓝色电路纹、短手短脚和唯一无牙小嘴。任何角度都不得把机体纵向拉长成鸡蛋形。

规范名称为“小耗儿”；“小内耗”“白色小电阻人”只作为历史别名，不得被模型当成新角色或不同角色。

没有底稿的常驻配角不得凭名字猜造型。先搜索项目资产；仍缺失时，将其标为待提供参考图，或明确建立原创角色卡后再生成。不得无意复制第三方商业角色。

## 先做时长审计

1. 按自然短视频普通话约每秒 4.2—5.8 个汉字估算；笑点另留 0.2—0.6 秒反应时间。
2. 目标时长装不下时，不使用 8—10 字/秒的失真高速朗读。优先缩短施压方对白、用动作交代前提、每场只完整说一句回击，或向用户提供延长版。
3. 快切小于 0.8 秒时只承载纯画面、极短声爆点或 2—4 字屏幕标签，不塞完整句子。
4. 把最终时间轴、总口播字数和预计语速写入制作稿。

## 拆成独立片段

- 每个 AI 视频片段只允许一名说话者、一个主要动作和一个明确情绪变化；情绪变化必须由这个唯一动作或声音力度体现，不得另加第二个可见动作。
- 多人对白拆成正反打；其他人物闭嘴、静止，不让模型在同一片段内轮流说话。
- 走位、泼水、越位、换道具等大状态变化使用两个状态关键帧加硬切，不强迫模型插值完成。
- 震屏、闪白、字幕、价格数字、BGM、复杂水花和人群反应放到后期。
- 每个独立片段至少制作一张代表性关键帧；只有进入与退出状态差异大、涉及不可稳定插值的道具或走位变化时，才为同一片段制作首尾两张状态帧。相同场景的后续帧同时引用永久母版和上一状态帧。
- 不让模型在单个片段内把小耗儿从正面转到侧面、背面或相反方向。机位方向改变时拆成独立镜头，并让各镜头引用对应六视图；没有对应角度时优先改机位或硬切，不凭文字临时重画角色侧背结构。

## 生成关键帧

1. 制作任何小耗儿图片提示词前，完整读取 [多视图与逐帧身份锁](references/多视图与逐帧身份锁.md)。
2. 每张图同时把永久正面母版标为最高身份参考，并按镜头方向选择正、背、左、右、左 3/4 或右 3/4 机位参考；两者都属于身份参考，不是风格参考。相同场景后续帧再加入上一状态帧。
3. 竖屏内容默认 9:16；主体、动作和后期字幕区避开平台按钮与底部裁切区。
4. 图片不生成字幕、数字、Logo、水印或媒体标识；文字统一后期添加。
5. 每次生成后检查角色拓扑、唯一嘴、无牙口型、四肢数量、场景人数、道具、角度与画风。失败图不得进入交付目录。
6. 把最终图片移入单集工作区，并记录文件名、尺寸、用途、对应镜头编号和所用机位参考。

## 编写制作包

至少交付：

- 单集 README 与简报
- 制作剧本、口播稿、字幕稿
- 连续性设定与分镜表
- 每张关键帧的图片提示词
- 每个独立片段的完整图生视频提示词
- 剪辑、声音、发布和交付说明

镜头编号使用完整格式 `第NNN集-镜头001`。每条视频提示词必须独立可复制，不依赖“同上”或只写在文档顶部的公共约束。

## 强制有声与固定音色

制作任何视频提示词前，完整读取 [声音与收紧合同](references/声音与收紧合同.md)。

硬要求：

1. 每个生成源片和每个交付视频都必须含可听见的非空音轨，禁止任何静音片。对白片必须含同步中文人声；无对白片必须含连续、可听但不抢画面的环境底噪。
2. 小耗儿跨全部片段使用同一个已验收声音参考或平台实际 Voice ID；不得每个 clip 重新描述、随机生成或更换音色。
3. 有多个常驻角色时，每个角色各有一套稳定的实际声音资产；同一角色的性别感、年龄感、音高、共振峰、口音、语速和近讲质感保持不变。
4. 明确区分项目内部 `voice_profile_code`（如 `VO-XH-01`）与平台真实 `provider_voice_id` / `reference_audio`。内部编号不能冒充平台 Voice ID。若工具支持参考音频、Voice ID、seed 或模型版本，所有片段必须复用同一组实际设置。
5. 先制作并验收一条 6—10 秒无 BGM、无混响、无环境声的角色干声样本，再批量生成多片段。
6. 若视频工具不能绑定同一声音资产，先用同一个已验收 TTS / 配音声音单独生成全部干声，再同步混入对应视频；如果连同一配音来源也无法复用，停止批量生成，不得把逐片随机声线交付为“固定音色”。
7. 每条对白提示词写明精确对白、开口时码、结束时码和末尾闭嘴停留；对白只说一次，不增词、不抢词、不由错误角色开口。无对白片明确写 `voice_profile_code：不调用`、全员闭嘴、禁止可辨识背景人声。
8. 生成片保留人声和极轻环境底噪即可；整集 BGM、惊雷、餐盘、水滴、脚步、打脸、重击和人群笑声统一后期添加，避免各片段声音风格断裂。

## 收紧视频提示词

每条提示词都必须独立重复 [多视图与逐帧身份锁](references/多视图与逐帧身份锁.md) 中的“逐帧身份锁”完整块，并明确：当前机位参考；固定机位或指定单一运镜；只做一个主要动作；人物数量与嘴部状态；道具起止状态；末尾停住；禁止复杂走位、肢体接触、多人同时说话、镜头漂移、自动加字幕、角色变形和新道具。同步自然口型不另算主要动作；除口型外只能再有一个小幅动作。手机、电视、广播等设备中的可辨识人声也算第二名说话者，默认改为后期叠加或使用无人声提示音。

宁可降低动作幅度、改用硬切或后期缩放，也不能让模型同时完成说话、走路、拿取、转身和大幅表情。

若视频模型支持 character reference、identity strength、reference strength、fixed seed 或 consistency 选项，统一使用已验收的同一角色引用与最高稳定档；参数不明时不虚构数值，在生成记录中写实际设置。任何一帧发生脸型、身材、腰带、锯齿纹、电路纹、头顶标志、嘴或四肢漂移，都判为失败片，不能靠字幕、裁切或短暂出现来放行。

## 质检与交付

逐个检查：

- 所有计划关键帧真实存在、能打开且尺寸正确。
- 主角与配角身份、服装、道具、场景状态连续；小耗儿关键帧记录了正面母版与对应角度参考。
- 每段视频提示词都包含有声硬要求、实际声音资产绑定或明确不调用人声、单一动作和负面约束；对白片另含逐字对白与时码，无对白片另含连续环境底噪与全员闭嘴约束。
- 每段视频逐帧抽查起始、四分之一、中点、四分之三和结束位置；小耗儿任一抽查帧偏离母版或对应角度参考就重生成，不把“只有几帧坏掉”视为可交付。
- 口播总时长符合目标，字幕每行适合手机阅读。
- 每个生成源片和最终交付视频都真实含非空音轨；同一角色跨片段的实际 Voice ID / 参考音频、音色、音高、语速和口音一致。
- 没有把不存在的图片、视频或音频写成已完成。

完成后更新单集 README 和剧集索引，验证链接与文件，按项目规则提交、推送并同步持久化上下文。
