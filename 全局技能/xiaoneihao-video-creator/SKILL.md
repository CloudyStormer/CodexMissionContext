# 小耗儿短视频创作

把用户原始创意转为可生成、可配音、可剪辑、可续接的单集素材。保留原稿作为来源，另建版本化生产稿，不暗中覆盖已确认版本。

## 开工

1. 按当前仓库规则同步上下文并检查 Git 工作树；保留用户已有修改。
2. 读取项目入口、账号定位、视频流程、剧集索引、当前或上一集 README，以及品牌角色锁定文件。
3. 使用 `aidrama` 组织剧情、分镜、连续性与交付；生成图片时使用 `imagegen`。
4. 没有指定集数时使用索引中的下一个编号；与旧集高度重复时保留为新版本或续集，并在 README 说明关系。

## 锁定创作输入

把用户明确提供的画幅、时长、风格、角色、台词、字幕、音乐和音效视为最高优先级。只在缺失时采用项目默认值，并把默认值写入工作假设。

固定主角必须使用仓库永久母版 `assets/brand/resistor-mascot-identity-master-original.jpg`。只允许改变动作、服装、道具、场景、光线、材质和有限表情；不得改变单一蛋形身体、五官、头顶黄蓝标志、浅灰电阻区域、锯齿纹、蓝色电路纹、短手短脚和唯一无牙小嘴。

没有底稿的常驻配角不得凭名字猜造型。先搜索项目资产；仍缺失时，将其标为待提供参考图，或明确建立原创角色卡后再生成。不得无意复制第三方商业角色。

## 先做时长审计

1. 按自然短视频普通话约每秒 4.2—5.8 个汉字估算；笑点另留 0.2—0.6 秒反应时间。
2. 目标时长装不下时，不使用 8—10 字/秒的失真高速朗读。优先缩短施压方对白、用动作交代前提、每场只完整说一句回击，或向用户提供延长版。
3. 快切小于 0.8 秒时只承载纯画面、极短声爆点或 2—4 字屏幕标签，不塞完整句子。
4. 把最终时间轴、总口播字数和预计语速写入制作稿。

## 拆成独立片段

- 每个 AI 视频片段只允许一名说话者、一个主要动作和一个明确情绪变化。
- 多人对白拆成正反打；其他人物闭嘴、静止，不让模型在同一片段内轮流说话。
- 走位、泼水、越位、换道具等大状态变化使用两个状态关键帧加硬切，不强迫模型插值完成。
- 震屏、闪白、字幕、价格数字、BGM、复杂水花和人群反应放到后期。
- 为每个独立片段制作关键帧；相同场景的后续帧同时引用永久母版和上一状态帧。

## 生成关键帧

1. 每张图都把永久母版标为角色身份参考，而不是风格参考。
2. 竖屏内容默认 9:16；主体、动作和后期字幕区避开平台按钮与底部裁切区。
3. 图片不生成字幕、数字、Logo、水印或媒体标识；文字统一后期添加。
4. 每次生成后检查角色拓扑、唯一嘴、无牙口型、四肢数量、场景人数、道具和画风。失败图不得进入交付目录。
5. 把最终图片移入单集工作区，并记录文件名、尺寸、用途和对应镜头编号。

## 编写制作包

至少交付：

- 单集 README 与简报
- 制作剧本、口播稿、字幕稿
- 连续性设定与分镜表
- 每张关键帧的图片提示词
- 每个独立片段的完整图生视频提示词
- 剪辑、声音、发布和交付说明

镜头编号使用完整格式 `第NNN集-镜头001`。每条视频提示词必须独立可复制，不依赖“同上”或只写在文档顶部的公共约束。

## 强制有声与固定音色

制作任何视频提示词前，完整读取 [声音与收紧合同](references/声音与收紧合同.md)。

硬要求：

1. 每个需要对白的片段必须生成可听见的同步中文人声，禁止静音、只有口型或只有环境声。
2. 小耗儿跨全部片段使用同一个声音参考或 Voice ID；不得每个 clip 重新描述或更换音色。
3. 有多个常驻角色时，每个角色各有稳定 Voice ID；同一角色的性别感、年龄感、音高、共振峰、口音、语速和近讲质感保持不变。
4. 若工具支持参考音频、voice ID、seed 或模型版本，所有片段必须复用同一组设置。若工具不支持，只靠文字不能承诺绝对声纹一致；仍须逐字重复同一声音锚点，并把该限制列为质检风险。
5. 先制作并验收一条 6—10 秒无 BGM、无混响、无环境声的角色干声样本，再批量生成多片段。
6. 每条提示词写明精确对白、开口时码、结束时码和末尾闭嘴停留；对白只说一次，不增词、不抢词、不由错误角色开口。
7. 生成片保留人声和极轻环境底噪即可；整集 BGM、惊雷、打脸、重击和人群笑声统一后期添加，避免各片段音乐断裂。

## 收紧视频提示词

每条提示词都必须明确：固定机位或指定单一运镜；只做一个主要动作；人物数量与嘴部状态；道具起止状态；末尾停住；禁止复杂走位、肢体接触、多人同时说话、镜头漂移、自动加字幕、角色变形和新道具。

宁可降低动作幅度、改用硬切或后期缩放，也不能让模型同时完成说话、走路、拿取、转身和大幅表情。

## 质检与交付

逐个检查：

- 所有计划关键帧真实存在、能打开且尺寸正确。
- 主角与配角身份、服装、道具、场景状态连续。
- 每段视频提示词都包含声音硬要求、固定 Voice ID、逐字对白、时码、单一动作和负面约束。
- 口播总时长符合目标，字幕每行适合手机阅读。
- 生成视频真实含音轨；同一角色跨片段的音色、音高、语速和口音一致。
- 没有把不存在的图片、视频或音频写成已完成。

完成后更新单集 README 和剧集索引，验证链接与文件，按项目规则提交、推送并同步持久化上下文。
