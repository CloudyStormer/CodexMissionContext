# 生产流水线与质检

## 静态帧

1. 读取本集剧本、分镜和前后镜头连续性。
2. 绑定角色、场景、服装、道具的正式参考路径与用途。
3. 生成首帧；逐项验收身份、人数、空间、视线、动作起态、时间和光线。
4. 首帧通过后，以正式首帧作为尾帧最高优先参考生成终态。
5. 原始输出与正式输出分开，失败稿记录原因和修法。

## 视频

只上传正式首尾帧生成无声低成本草稿。检查人物身份、动作物理、空间、物体、终态和镜头运动。失败时按顺序修：身份 → 人数 → 空间 → 动作 → 道具服装 → 光线时间 → 构图美化；一次只改一个主变量。

画面锁定后再加入配音、环境声、字幕、音乐和高清输出。

## 阻塞

- 故事、人物、时间线互相矛盾。
- 双主角没有同板通过或失败图进入正式锚点。
- 分镜编号重复、时长无效、提示词缺失或引用不存在。
- 首尾帧未通过就进入视频。
- 样片未通过就批量生成。
- 声称素材存在但文件打不开或不存在。
