## 设备 B 创建规则

1. 先完成对应项目的本地接入。
2. 若任务标题已存在，记录它的本地线程 ID，不重复创建。
3. 若不存在，读取上下文文件，在对应项目下创建任务。
4. 创建后把标题改成清单中的精确标题。
5. 新任务只需确认“上下文已导入，等待继续”，不得擅自继续执行遗留工作。
6. 把设备 B 的本地线程 ID 写入 `设备/B/任务映射.md`。

线程 ID 是设备本地标识，A、B 不要求相同；标题、项目归属和持久化上下文必须一致。
