## Windows 项目位置

- Windows 设备上的所有共同项目统一放在 `D:\.aaProject-Bruce\` 下。
- `CodexMissionContext` 的固定位置是 `D:\.aaProject-Bruce\CodexMissionContext`。
- `lottery` 的固定项目根目录是 `D:\.aaProject-Bruce\lottery`。
- `vid-mat-lab` 的固定项目根目录是 `D:\.aaProject-Bruce\vid-mat-lab`。
- 禁止把共同项目克隆、创建或迁移到 C 盘；Git、Codex 等系统程序自身安装在 C 盘不属于本限制。
- Windows 上的共同任务直接使用 D 盘已保存项目，不为共同项目在 C 盘创建 Codex worktree 或代码副本。

## ChatGPT 云项目

设备 A 还显示一个名为 `22` 的 ChatGPT 云项目。它由同一 ChatGPT 账号管理，不通过本地 Git 清单重建，也不纳入本地项目删除或对齐操作。

## 明确排除的个人项目

- `AI学习`：设备 A 个人使用。保留 A 端现有项目，不删除；设备 B 不创建，双设备同步流程不读取、不更新、不报告为阻塞。

## 强制规则

- 只添加缺失项目。
- 不删除、不归档、不重命名、不隐藏任何现有项目。
- 某台设备存在额外项目时，只报告差异，保持原样。
- 本地路径及本地 `projectId` 可以不同，分别记录到设备映射；左侧名称和逻辑项目 ID 必须一致。
- Windows 设备的本地路径虽可与 macOS 不同，但必须满足本清单的 `D:\.aaProject-Bruce\` 根目录约束。
- 项目内容未准备好时，不创建空壳冒充完整项目；应标记阻塞并先修复 Git 来源。
- 用户明确把某项移出共同范围时，只从共同清单排除；各设备已有项目继续保留，不能据此删除或归档。
