## Windows 项目位置

- Windows 设备上的所有共同项目统一放在 `D:\.aaProject-Bruce\` 下。
- 上表每个项目的 Windows 根目录均为 `D:\.aaProject-Bruce\<目录名>`，不得放到 C 盘。
- 共同任务直接使用 D 盘已保存项目，不为共同项目在 C 盘创建 Codex worktree 或代码副本。
- Git、Codex 等系统程序自身安装在 C 盘不属于本限制。

## 强制规则

- 只添加缺失项目；不删除、不归档、不重命名、不隐藏任何现有项目。
- 本地路径和 `projectId` 可以不同，分别写入设备映射；显示名称差异只记录，不自动改名。
- 项目内容未准备好时，不创建空壳冒充完整项目；应记录阻塞并先修复 Git 来源。
- Windows 设备的共同项目必须位于 `D:\.aaProject-Bruce\`。
- 用户明确把某项移出并集范围时，只从同步范围排除；各设备已有项目继续保留。
