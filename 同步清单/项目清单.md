## 强制规则

- 只添加缺失项目。
- 不删除、不归档、不重命名、不隐藏任何现有项目。
- 某台设备存在额外项目时，只报告差异，保持原样。
- 本地路径不同可以记录设备映射，但左侧名称和逻辑项目 ID 必须一致。
- 项目内容未准备好时，不创建空壳冒充完整项目；应标记阻塞并先修复 Git 来源。
