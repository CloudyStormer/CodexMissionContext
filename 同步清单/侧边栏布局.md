## 版本规则

- 当前设备落后于另一端发布版本时，先应用远端布局，不发布本机旧布局。
- 当前设备完整应用最新版本后，用户调整共享项目顺序或置顶并再次发送“开始同步”，才发布下一版本。
- 目标设备缺少对象时保留逻辑位置并标记部分应用，不发布残缺的新版本。
- 部分应用不提升“已完整应用版本”；必须另记目标版本和未完成逻辑 ID。
- 应用时保持所有非共享对象的置顶状态及其在各自区域内的相对顺序，只重排共享对象子序列；不能保证时不执行整体重排。
- 同一旧版本被两端并发发布为不同下一版本时停止自动选择并报告冲突。
- 应用排序和置顶只能使用正式 Codex API 或用户可见界面；严禁直接写 Codex 原始状态或数据库。
